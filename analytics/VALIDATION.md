# Итог проверки аналитики

## Воспроизводимые проверки

Среда: Python 3.12, SQLite, SQLAlchemy 2.1.9, Plotly 6.9.0. В репозитории иных файлов автоматических тестов, кроме набора `analytics/test_*.py`, на момент проверки не обнаружено.

| Проверка | Результат |
|---|---|
| `python -m unittest discover -v` | 39 тестов, все пройдены, без пропусков |
| `python -m analytics.verify_notebook` | 8 исполняемых ячеек × 4 успешных запуска; повторяемость из корня и `analytics/` |
| `python -m compileall -q analytics` | Успешно |
| `git diff --check` / `git diff --cached --check` | Без ошибок пробелов после нормализации перенесённых файлов |
| Арифметика прежней таблицы сегментов | 8 строк дают 1 918 пациентов и 129 217 716,86 ₽ |

Исходные 20 тестов прошли до правок. Новые регрессионные проверки воспроизвели обнуление возвратов, пропуск компенсирующихся ошибок выручки, устаревших счётчиков визитов и визита без записи пациента. После исправлений весь набор проходит.

Дополнительные две регрессии первой услуги: возвраты, сторно и нулевое количество исключены; при услуге без даты первая услуга отмечается как неизвестная.

## Покрытие

- Все восемь сегментов; пороги 60, 90 и 180 дней; приоритеты новых и лояльных пациентов; завершение цепочек.
- RFM при одинаковых значениях, пропусках и разной давности визита.
- Возвраты в историческом LTV, неотрицательный прогноз, когорты разной длительности, недавние когорты и отсутствие достаточной истории.
- Повторный запуск, пустая база, заполнение пропущенных метрик по истории, неизменность базовых полей и исходных таблиц, откат при сбое записи.
- Скидки, корректировки, первая категория, соседние переходы и сверка выручки по отдельным визитам.
- Календарные суммы, пустые месяцы, незавершённые окна удержания, эффект сверх органического возврата, восемь сериализуемых графиков с пояснениями.
- Реальные вызовы CLI: сегментация → JSON/CSV услуг, автономный HTML с восемью графиками, ошибка отсутствующей схемы без traceback, отсутствие изменений базы после читающего отчёта.

Ноутбук проверен валидатором nbformat и непосредственным выполнением ячеек в IPython. Запуск отдельного Jupyter-ядра через TCP/IPC в этой среде блокировался ограничением сокетов; это не заявляется как пройденная проверка сетевого ядра. Источник ноутбука не изменяется проверяющей командой, outputs остаются пустыми.

## Проверка публикации

Проверяются staged-файлы и итоговый diff относительно `origin/main`: только `analytics/`, текстовые исходники, документация, requirements и очищенный `.ipynb`. Проверка включает расширения, сигнатуры SQLite/архивов, секреты и содержимое ноутбука. Содержимое исходников и документации просмотрено; идентификаторы и имена в тестовых данных генерируются из явно вымышленных записей. Данные пациентов, рабочие базы, Excel, архивы и реальные агрегированные JSON не добавляются. В `analytics/.gitignore` расширены исключения локальных выгрузок.

Эта проверка относится к изменениям данного PR, а не к независимому аудиту всей ранее опубликованной истории репозитория.

## Что не подтверждено

Исходная `data/ilfa.db` отсутствует: полный архив не пересчитан, точность прогноза на отложенном периоде не измерена. Цифры клиники в документации сохранены из прежнего отчёта с этим ограничением. PostgreSQL не проверялся. Автоматические тесты используют только синтетические данные.
